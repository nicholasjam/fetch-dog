# Fetch Dogs

A simple React application to fetch and display dog data.

## Installation

To get started with the project, follow these steps:

1. Clone the repository:
   ```bash
   git clone
   ```

2. Navigate into the project directory:
   ```bash
   cd fetch-dogs
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

## Scripts

- **Development server**:
   To run the development server:
   ```bash
   npm run dev
   ```

- **Build project**:
   To build the project for production:
   ```bash
   npm run build
   ```

- **Lint the project**:
   To run the ESLint checks:
   ```bash
   npm run lint
   ```

- **Preview production build**:
   To preview the production build locally:
   ```bash
   npm run preview
   ```

- **Run Cypress tests**:
   To open Cypress test runner:
   ```bash
   npm run cypress
   ```

   To run Cypress tests in headless mode:
   ```bash
   npm run cypress:run
   ```

   To run end-to-end tests with dev server:
   ```bash
   npm run test:e2e
   ```

   To run end-to-end tests in CI environment:
   ```bash
   npm run test:e2e:ci
   ```
